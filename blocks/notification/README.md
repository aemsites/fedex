# Notification

A one-cell informational notice with an info icon (`/icons/info.svg`, applied as a CSS mask in the brand blue). Extra cells are merged.

| Notification |
|---|
| Notice text with optional inline links |

## Variants
- *(none)*: informational notice: brand blue border with a 4px left accent, light blue tint, info icon
- `warning`: warning notice: amber (`--warning-color`, #f7b118) border with a 4px left accent, amber tint (`--warning-background-color`, #fefaf1) and a warning-triangle icon (`/icons/warning.svg`, drawn as a background image because it is two-colour). Example: `Notification (warning)`
