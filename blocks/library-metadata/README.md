# Library Metadata

The name and description of a block library sample. Each section of a library document (`docs/library/blocks/<block>`) holds one sample block followed by this table; the DA Library panel ("Blocks") shows the name and description from it.

| Library Metadata | |
|---|---|
| name | Cards (promo, centered) |
| description | Borderless image-top cards, CTA pinned to the bottom |

On the rendered page the block (and its wrapper) is hidden, so previewing a library document shows only the samples. Not for site pages; written by `tools/library/gen-block-library.py`.
